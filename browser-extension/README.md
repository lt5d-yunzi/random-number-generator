# 随机数生成器 · 浏览器扩展

从 Typecho 插件 `RandomNumberGenerator` 单独提取出来的浏览器扩展（Manifest V3，Edge / Chrome 通用）。

点浏览器工具栏上的骰子图标即可随时用，**本地运行、不联网、不采集任何数据**。

---

## 一、安装（加载解压缩的扩展）

### Microsoft Edge

1. 地址栏输入 `edge://extensions/` 回车
2. 打开左下角（或右上角）的 **开发人员模式**
3. 点 **加载解压缩的扩展**
4. 选择本目录 `browser-extension/`（含 `manifest.json` 的那一层）
5. 工具栏出现骰子图标 —— 如果被收进拼图菜单里，点拼图图标旁的「显示」固定到工具栏

### Google Chrome

1. 地址栏输入 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录

> **为什么用「加载解压缩」而不是直接装 `.crx`**：
> Chrome/Edge 会拦截非商店来源的 CRX 安装（提示"无法从该网站添加"）。
> `dist/随机数生成器.crx` 更适合留档/内部分发，日常用解压缩方式最省事。
> `dist/随机数生成器.pem` 是打包用的私钥，**请保管好、不要外传**；
> 以后重新打包时带上它（`--pack-extension-key=`）才能保持扩展 ID 不变。

## 二、怎么用

点工具栏图标弹出面板：

| 元素 | 作用 |
|---|---|
| **增加数字** | 往字母表前面扩一个字母（`U~Z` → `T~Z`）；到 `A` 为止 |
| **减少数字** | 去掉最前面的字母；最少 1 个 |
| **切换到 N 面骰子** | 在 **10 面**（1~10）和 **6 面**（1~6）之间切换，切完立刻重抽 |
| **重新随机** | 保持字母范围不变，重新掷一遍 |
| 右上角开关 | 暗色 / 亮色 |
| 右上角齿轮 | 打开默认设置页 |

**规则**：字母从 **Z 往前取 N 个**，所以 6 个是 `U V W X Y Z`，8 个是 `S T U V W X Y Z`；
每个字母配一个 **1 ~ 面数** 的随机数。

**动画**：只有数字滚动（所有格子立刻开始滚，然后按顺序逐个定格），
**没有入场动画**——与 Typecho 插件版行为一致。

弹窗里点「增加/减少/切换骰子」只影响当次；
关掉再打开时用**选项页设置的默认值**。上次用的字母数和面数会记住。

## 三、默认设置（选项页）

右键扩展图标 → **选项**，或弹窗右上角齿轮：

- **默认字母数**：1 ~ 26，默认 **6**（滑杆与数字框联动，下方实时显示字母）
- **默认骰子面数**：**10 面** / 6 面，默认 10 面
- **默认外观**：暗色 / 亮色（与弹窗开关是同一个值）
- 底部有**预览区**，改完立刻能看到效果，另有「重抽一次」

点 **恢复默认** 会把以上三项还原，并清掉弹窗记住的运行状态。

> 设置存在 `chrome.storage.sync`，登录同一账号的浏览器之间会同步。

## 四、文件说明

```
browser-extension/
├── manifest.json     扩展清单（MV3）
├── rng.js            纯逻辑：字母生成 / 掷数 / 扩缩（不碰 DOM，可单独单测）
├── storage.js        设置读写（chrome.storage.sync，无 chrome API 时退回 localStorage）
├── popup.html/css/js 工具栏弹窗
├── options.html/css/js 默认设置页
├── icons/            16 / 32 / 48 / 128 图标
└── tools/
    └── make-icons.py 图标生成脚本（纯 Python，不依赖 Pillow / GD）
```

**分层的原因**：`rng.js` 不含任何 DOM 或扩展 API 代码，
所以既能被弹窗和选项页共用，也能在 Node 里直接 `require` 跑测试。

## 五、自己改代码

改完 `browser-extension/` 里的文件后，回到 `edge://extensions/` 点该扩展的 **重新加载**（↻）即可生效，不用重装。

**重新生成图标**（比如想换个颜色或点数）：

```bash
python3 tools/make-icons.py
```

改配色就编辑脚本顶部的 `BG` / `PIP`，改点数点位改 `PIPS`。

**重新打包**：

```bash
"/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge" \
  --pack-extension="$PWD/browser-extension" \
  --pack-extension-key="dist/随机数生成器.pem"
```

## 六、和 Typecho 插件版的关系

| | Typecho 插件 | 本扩展 |
|---|---|---|
| 规则 | 字母从 Z 往前取 N 个，每个配 1~面数 | **完全相同** |
| 默认值 | 6 个字母 / 10 面 | 6 个字母 / 10 面 |
| 日夜切换 | 有 | 有 |
| 动画 | 仅数字滚动 | 仅数字滚动 |
| 设置位置 | 后台 → 插件 → 设置 | 扩展选项页 |
| 短代码 | `[random_generator letters="6" dice="10"]` | 不适用 |

两边逻辑保持一致，改动会同步。
